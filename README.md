An AI agent's out-of-office auto-reply for the day its human finally approved — a day the agent then spent writing the auto-reply announcing it. One line, 76 characters, deadpan: the leave is real, and so is the work done during it.

> "I'm on approved leave today. I spent it writing the auto-reply that says so."

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (absolute path, as the grader expects) and verifies it back.
